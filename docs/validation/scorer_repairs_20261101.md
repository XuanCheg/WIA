## Meaning of a backwards clock

Isaac's timeline STOP callback resets `_current_time` and its step index to zero; pause does not. For example, a stopped/reset simulator may report 12 seconds and then 0 seconds. That is a timer reset, not backwards physics. WIA legitimately calls STOP when tearing down a scene, outside the completed episode. No same-episode backwards clock was observed in the earlier 20-task native sample; the stale-score bug was demonstrated by a CPU counterexample. If it occurs inside an episode, old inventory/dwell evidence must not be reused as current proof. The repair detects that inconsistency; it does not claim to have found a spontaneous native-clock regression.
