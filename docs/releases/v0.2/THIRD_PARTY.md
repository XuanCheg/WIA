# Component and resource boundaries

- WIA source contributions and authored release definitions retain the WIA repository's Apache-2.0 license. The license does not grant rights to third-party content.
- ShowHarnessExplore retains its original Apache-2.0 license, source attribution and citation metadata. Its source snapshot has been reorganized for the split dataset interface and contains local implementation changes recorded by file hashes.
- ESI-Bench is an external dependency at commit `9f6f15ed43e81654a97de9e4db2a1fedadca2bc1`, from `https://github.com/ESI-Bench/ESI-Bench`. The local pinned checkout has no tracked LICENSE file. These archives therefore do not redistribute its corpus or source code, or label it as WIA-owned. Obtain it separately and consult its upstream terms. Required source identities and hashes are recorded in the dataset dependency manifest.
- BEHAVIOR/OmniGibson native assets, simulator binaries, USD scene data, asset encryption keys and model weights are not included. Install and use them under their own applicable terms. A resource path or hash is not an asset license.
- InteractiveWorld research task references are provenance identifiers for adapted mechanisms. Original taskpacks are not included; the exported rigid-body/event-state definitions do not claim equivalence to unsupported cutting, liquid, contamination or deformable physics.
- Python and optional backend/simulator dependencies retain their own licenses. Installation extras describe software dependencies; they do not include external accounts, credentials or GPU drivers.
