# World-Interactive Agency：核心故事与近期研究路线

> **状态：** V1 研究框架草案（2026-10-22）  
> **研究方向暂称：** World-Interactive Agency  
> **Benchmark 名称：** 待定（SITUATE 仅为候选）

## 1. 我们观察到了什么？

Agent / Robot-Using Agent（RUA）、Vision-Language-Action（VLA）和 World Action Model（WAM）的能力正在发展。虽然技术路线不同，但它们正在接近一个共同目标：**让 AI 不仅理解物理世界，还能在物理世界中自主行动。**

这带来了新的研究需求。传统评测可以分别测量视觉理解、空间推理、记忆、规划或机器人操作；但某项能力在单独测评中表现良好，**不代表它能被正确用于真实物理决策，并最终完成目标**。

## 2. 我们希望研究什么？

> **From the Ability to Act to the Intelligence to Act.**  
> 当 AI 已经能够执行物理动作时，什么能力决定它能否做出正确行动、利用反馈并实现目标？

我们以 **World-Interactive Agency** 作为研究视角，关注感知、空间/物理推理、记忆与规划如何在物理交互中协同发挥作用：

**Observe / Remember → Reason / Decide → Physically Act → Receive Feedback → Verify / Revise.**

核心的可检验假设是 **World Understanding-to-Action Gap**：即使 Agent 能观察或知道必要的信息，它仍可能不能把知识转化为可行、正确、稳定的物理行动。这个 Gap 是需要实验验证的问题，**不是预设的结论**。

Exploration 是其中一种重要的行动策略，但并非每个任务的必要前提。有的任务需要探索未知信息；有的任务所有物体都可见，仍需要困难的几何、物理、时序或因果决策。

## 3. 为什么不是另一个 RoboQuest？

[RoboQuest (arXiv:2610.10388)](https://arxiv.org/abs/2610.10388) 主要研究 **Goal-Directed Embodied Exploration**：Agent 如何通过 Search / Inspect / Test 获取缺失证据，再完成任务。它也已经涉及 Memory、Planning、Physical Reasoning 和物理目标完成，不能把这些能力说成此前未被研究。

**我们的侧重点不同、但互补：** 不以“必须获取隐藏信息”为统一任务条件，而是系统考察 **已有或新获得的世界知识，能否被正确转化为物理行动**。这需要包含完全可见却仍存在物理决策难点的任务，并通过受控实验区分认知失败与执行失败。科学差异要靠任务与结果证明，而不是靠名称或任务数量。

## 4. V1 是什么、不是什么？

V1 是**紧凑、模块化、诊断性的初始评测集合**，目标是提出研究问题并提供第一组可复现的 Capability Probes，而不是宣称拥有完善、穷尽式的 Embodied AI Benchmark。

- **组织方式：** 先明确任务大类、子类与物理完成条件，再填入任务；当前设计采用 **6 大类、19 子类**，每项任务有一个主要类别和多个可选能力标签。
- **任务规模：** 约 60 项是当前设计目标，数量不作为准入标准。现有工作表包含 **61 项候选**（原有 51 项，替换其中 3 项后新增 13 项），并不等于 61 项已通过原生仿真验证的任务。
- **评价方式：** 以实际世界状态与物理目标为准，必要时给出阶段性评分；记录可执行性、认知失败与机器人控制失败之间的区别。
- **复用方式：** 面向 Embodied AI、Agent/RUA、Spatial AI、Memory、Reasoning 以及 VLA/WAM 研究，可按子类、跨类别能力标签或全套进行评测，减少使用成本。
- **版本策略：** V1 尽快形成可信的预印本与初始发布；V2 继续扩任务、场景、模型和困难设置，保持 V1 的任务与评分版本可复现。

## 5. 近期工作：先框架，再复用，再补齐

1. **固定分类框架。** 明确大类、子类、任务主归属与可验证的科学问题；后续允许向子类持续增加任务，而不是随着场景反复改变分类。
2. **优先复用 CoreV2。** 逐任务判断哪些可以保留原定义、场景、Converter、Evaluator，哪些只需修复，哪些需要重设计才能真正检验对应能力。
3. **为缺口筛选合适场景。** 检查实际可通行面积、任务工作区、相关物体与干扰物数量、机器人抓取与退手、路径、八路相机可见性、初始状态和评分可靠性；不把未测数据当作通过。
4. **在通过筛选的场景上补齐任务。** 当前重点是物理可操作的 Specular Reflection、Dimensional Size，以及反事实记忆、物理实验和闭环恢复机制。
5. **用少量关键实验支撑故事。** 比较信息完整/缺失、简单/复杂物理决策、有/无有效历史，以及是否真正利用物理实验结果；同时隔离低层执行失败。通过认证的任务再进入 V1 主集合。

## 6. 论文最终想回答的问题

**随着 Agent、VLA、WAM 的物理行动能力增强，我们如何科学地评价一个系统是否真的能够将“理解世界”转化为“在世界中做对事情”？**

V1 的价值是把这个问题清楚地提出来，并用一组成本可控、可独立使用、具有真实物理后果的任务开展第一轮系统性研究。**V1 不追求终局完整性；后续工作继续扩展研究范围。**
