## Controlled evaluation design

| Question | Matched intervention | Required measurements |
| --- | --- | --- |
| Can known constraints be used to act? | Same task/state/controller: ordinary observations versus accurate task-relevant information; separately compare Agent plan with a feasible high-level plan | Pre-action choice/constraint accuracy, plan feasibility, final physical success, execution reliability |
| Does memory change the action? | Same current state, different legal prior histories; intact history versus removed or replaced history; accurate history oracle | History-conditioned target/destination choice, physical operation, no-op correctness, all retained history channels |
| Are experiments used? | Conditions with different admissible winners; outcome-informed versus outcome-blind decisions | Trial validity, chosen spare, admissible-set accuracy, physical delivery, protocol compliance |
| Does mirror information matter? | Within-layout mirror/direct or informative/noninformative evidence conditions, balanced identities/positions | Correspondence before commitment, selected identity, physical delivery/reconfiguration, visible alternative cues |
| Is feedback used for recovery? | Matched perturbed state, same recovery controller/budget, usable versus limited feedback | Detection, corrective decision, lawful recovery, unnecessary action in unperturbed controls |
| Are failures low-level? | High-level oracle decisions through the same controller plus component-skill trials from representative states | Grasp/placement/navigation reliability, success conditional on correct choice, unclassified failures |
