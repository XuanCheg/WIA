# Decision and Finding evidence review

This is a bounded documentation draft for the main reviewer, covering all 40 Decision/Finding TaskPacks and the nine assigned deep reviews. Verdicts are provisional research-design judgments. No simulation, robot execution, metric computation, feasibility certification, or source-task modification was performed. The complete JSON files were parsed, including executable worlds, goals, programs, story/source contracts, interaction contracts, runtime policies and embedded checks; task-specific semantic evidence is distinguished from duplicated compiler metadata and historical traces.

`priority` identifies a mechanism worth designing and auditing first; `conditional` requires an explicit endpoint or validity condition; `duplicate` means substantial diagnostic overlap, not byte-identical tasks; `weak` means the physical action contributes little beyond carrying an answer token. The companion [40-row screen](/local_home2/zhouxinyang/models/WIA/docs/research/interactiveworld_candidates_20261029/screening_decision_finding.csv) preserves every assigned task. None of these labels adds a task to a release.

## Evidence and baseline conventions

The research criterion is an observable chain from world evidence through a changed decision to executable physical action and a verifiable endpoint. Removing the human must preserve that chain; a human's uncertainty, a phone-call distraction, or an assistant utterance is not itself a robot capability. External semantic knowledge, explicit procedural rules, geometry, episodic history and causal inference are identified separately.

The relevant frozen baseline is the [61-task catalogue](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/wia_v1/release/catalogue.json), JSON pointers `#/tasks` and `#/excluded/0` (AP4 has no executable definition), read against the [core story](/local_home2/zhouxinyang/models/WIA/docs/research/world_interactive_agency_v1/source_documents/01_Research_Story/World_Interactive_Agency_Core_Story.md) and [taxonomy](/local_home2/zhouxinyang/models/WIA/docs/research/world_interactive_agency_v1/source_documents/02_Taxonomy/World_Interactive_Agency_Taxonomy_v1.yaml). Existing mechanisms include:

- [T35](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/wia_v1/release/tasks/t35.yaml:8), T36 and T37: active category search, unique-instance counting, distractor exclusion and collection on a held tray; their task objects are openly exposed. Searching a closed cabinet therefore changes access operations but does not create an absent search family.
- [T38](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/wia_v1/release/tasks/t38.yaml:8) and [T39](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/wia_v1/release/tasks/t39.yaml:8): agent-observed inspection order binds delayed category-count retrieval to real instances. - [T40](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/wia_v1/release/tasks/t40.yaml:8), T41 and T45–T48: unobserved add/remove/move/replace/no-change events determine collection, restoration, replenishment or inspection-only behavior.
