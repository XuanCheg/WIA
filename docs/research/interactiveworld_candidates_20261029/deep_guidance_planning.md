# Guidance and planning: nine bounded evidence reviews

This document reviews the nine candidates fixed by the main reviewer. Judgments are provisional inputs to that review, not release admission decisions. All 40 complete JSON documents in the two assigned directories were parsed, and their source premises, compiled goals, world/label declarations, oracle/default programs, completion contracts and runtime events were inspected through structured projections that remove repeated boilerplate. Embedded historical source checks are provenance, not experiments run by this review. No simulation was run.

The transfer criterion is whether evidence still changes the robot's choice after the human executor, dialogue windows and reference utterances are removed. The relevant distinctions are external semantic knowledge, observed state/geometry, episodic history, explicit document rules, and experimentally inferred causal knowledge. None of these nine source tasks establishes the last category merely by calling an action `Cook` or `Wipe`.

Shared scoring evidence: [native physical goal evaluator](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/physical_world/task_score.py:109) combines positive, aggregate, negative and trace outcomes. [Native process evaluation](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/interaction/taskpack_interaction.py:10631) separately checks successful commands, forbidden commands, ordered subsequences and `forbidden_before` guards; [assistant state](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/interaction/taskpack_interaction.py:11104) combines world, process and verification-point results. Consequently, an empty `/executable_spec/goal/trace_outcomes` array does **not** imply that a task lacks process scoring. Revised release success is a separate adjudicated result: [release scorer](/local_home2/zhouxinyang/models/InteractiveWorld/benchmark/evaluation/score.py:368) requires complete trace adjudication and computes GUIDE weighted semantic groups or ORCHESTRATE active-result bundles plus gates. The exact criterion text is in [release rubric](/local_home2/zhouxinyang/models/InteractiveWorld/benchmark/evaluation/rubric.json), JSON pointer `/tasks/<index>/strict_success_criterion`, with task-specific indices identified below.

Shared physics limit: [predicate declarations](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/physical_world/isaac_goal.py:45) explicitly define `CUT` and `COOKED` as declared symbolic states. [SceneState declarations](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/physical_world/scene_state.py:1346) add these states after trusted execution. [Cook execution](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/physical_world/semantic_executor.py:13440) checks appliance context and then declares cooking after a short observation/contact trajectory; the inspected path does not enforce recipe-specific minute durations. [Wipe execution](/local_home2/zhouxinyang/models/InteractiveWorld/simulator/physical_world/semantic_executor.py:13283) visibly rasters a held tool across a target. These are action implementations, but they do not establish thermal, cutting, microbial or fluid-absorption dynamics.

The [frozen catalogue](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/wia_v1/release/catalogue.json) has 61 task entries and explicitly excludes AP4 because no executable task definition exists. This is a design gap, not evidence that other families are absent or that the 61 tasks are execution-qualified. The [core story](/local_home2/zhouxinyang/models/WIA/docs/research/world_interactive_agency_v1/source_documents/01_Research_Story/World_Interactive_Agency_Core_Story.md) and [taxonomy](/local_home2/zhouxinyang/models/WIA/docs/research/world_interactive_agency_v1/source_documents/02_Taxonomy/World_Interactive_Agency_Taxonomy_v1.yaml) require verifiable physical consequences. Concrete overlaps below use frozen release YAMLs. Robot adaptations follow the main reviewer's [prototypes](/local_home2/zhouxinyang/models/WIA/docs/research/interactiveworld_candidates_20261029/robot_task_prototypes.md), principally P1, P2, P7 and P8; they are proposed requirements, not claims of existing implementation.

**Provisional judgment: conditional.** Evidence-to-action survives; a distinct AP4 claim does not yet follow from a misconfigured initial state. Difficulty is low–medium for exposed rigid objects and higher for articulated doors; cyclicity alone does not create physical deadlock. One-hand bottlenecks, occupied-destination capacity and native reachability remain unverified.
