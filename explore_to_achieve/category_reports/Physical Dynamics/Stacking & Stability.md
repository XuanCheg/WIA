## Implemented goal and native evidence

The robot chooses the bottom object on the original floor, grasps and lifts each upper object at least 0.05 m, places it into support contact before opening the gripper, withdraws, and leaves a three-object tower stable for one second. Physical unstacking and rebuilding can test another order. Any independently stable order completes this physical recipe; the exact original accepted-order agreement is a separately labelled private auxiliary measure. This is an explicit semantic distinction, not a rewrite of source answers or their scorer.

The owned `category_operation` qualifier checks original native identity, scale and initial pose, movable collidable objects, independent floor `OnTop`/`Touching`, upright stationary starts, empty hands, and a supported obstacle-free R1 footprint in the source room. The evaluator reads native state through the existing control callback; it issues no robot actions, object mutations, kinematic placement, or simulator stepping. It requires measured working-arm attachment and lift history for both terminal upper objects, a supported release event for each, native `OnTop` and `Touching` for floor/bottom, bottom/middle and middle/top, and no other external support contact. Both arms must have no held object, constraint or pending release; the working gripper must be open.

Stability requires upright local Z dot world Z >= 0.9, linear speed <= 0.02 m/s and angular speed <= 0.1 rad/s for all objects, at least 1.0 s of consecutive native simulator-step samples, at least 20 distinct timestamps, and no sample gap above 0.1 s. Maximum position drift is 0.01 m and maximum orientation drift is 3 degrees relative to the start of the window. Missing support, contact with the robot/furniture, attachment, tilt, motion, excessive drift, or a sampling gap resets the window. These are sampled simulator-step checks, not a claim that every internal PhysX substep was observed. Original scale preservation and accepted native initial preconditions also gate completion. No legacy QA flag gates physical success.
