## Retained implementation and exact predicates

Recipe selection is a deterministic hash of source identity and seed; `correspondence_operation` can explicitly select either recipe. `correspondence_max_steps` defaults to 300, a new uncalibrated decision budget, not a inherited experimental configuration.

- `correspondence_approach`: navigate to the original central-ray target and stop 0.55–0.90 m from its measured native root, facing it within 25 degrees and at least 0.10 m closer to it than either distractor.
- `correspondence_approach_return`: complete the same stable approach, then return within 0.20 m of the measured episode-start XY and face the mirror within 25 degrees.

Both require at least 0.75 m measured travel, a 0.50 m excursion, upright floor support, no native external nonfloor contacts, chassis XY exclusion and full-robot AABB exclusion from the visual-only mirror/props, and five consecutive settled terminal control samples. Settled means chassis linear speed at most 0.02 m/s and angular speed at most 0.1 rad/s. Episodes beginning within 1.10 m of the target must leave that neighborhood before the approach can count. Position/yaw continuity uses the existing guarded controller speed/tolerance configuration and native simulation time; unsampled movement, source-asset displacement, lost support or collision invalidates success. This is a physical navigation goal, not an answer check.

The independent optical check recomputes the source generator's horizontal reflection formula from the fixed original observer XY and native mirror transform/local X normal and native prop roots. Exactly one forward candidate must be within 0.02 m of the reflected ray and match the independently corroborated original target. Every anchor must remain within 0.02 m and 0.5 degrees of its original pose. This does not claim a three-dimensional optical or rendered-visibility proof. QA answers/assignment visibility flags are absent from terminal success evaluation.

Native qualification additionally checks installed R1/holonomic base semantics, guarded base capabilities, source start XY within 0.05 m, heading within 2 degrees, and native mounted RGB/calibration with the mirror center inside the frustum. Frustum coverage is geometric; it does not establish an unobstructed, legible reflected target. All qualifier/evaluator hooks only read measured state. No simulator steps, transforms, robot actions or sensor mode changes are issued by these hooks.

The original variant remains empty. The adapted variant declares only one `robot_pose` initialization patch. Original material, scale, source observer, prop arrangement and physics remain intact. The shared pipeline already creates R1; `add_existing_r1` would duplicate it. The active builder restores every original mechanism used here, and all 88 sources have empty cleared-obstacle lists, so no `category_initialization` patch is justified. Navigation does not need movable props, so no `object_physics` patch is applied. A later manipulation recipe would need both source support qualification and physics restoration after postprocessing; it is not certified by this batch.
