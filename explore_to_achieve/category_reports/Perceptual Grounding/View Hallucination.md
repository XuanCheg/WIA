All 437 source targets omit scale, so retaining the constructor's default is faithful source reuse rather than a rescaling rule. The original reference-selection rule chooses the first visible non-topdown view, falling back to the first non-topdown view if necessary. All 437 selected references are ring views with true saved visibility metadata: 352 select view zero and 85 select a later view. Keep that exact original rule, rather than force the first saved frame. Those visibility flags are source metadata, not current native robot sensor measurements.
