# Prompt components

[main.md](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/prompts/main.md) assembles whitelisted resident instructions and fresh decision inputs. `@include` declares mandatory instructions, `@slot` inserts authorized public data, and `@plugin` declares an optional component whose activation is fixed when the episode assembler is created.

The [world observation plugin](/local_home2/zhouxinyang/models/WIA/explore_to_achieve/prompts/plugins/world_observation.md) is enabled by default for native declarative task episodes. Each response has one executable `command` and a separate public `world_observation` string. Commands retain their validation schema, bounds, and physical evaluation. The runner writes observations to `episode/world_observations.jsonl`, correlated by step, attempt, action boundary, and snapshot. It does not inject these descriptions into later prompts, public memory, recovery, control, or scoring. The model's own public outputs remain in its native conversation history.

Physical-task responses use `structured_fields_v1`: `answer` is null or a task answer, `arrived_rooms` is an array of current public room-instance declarations, and `survey_complete` is a boolean. Unused fields are null, empty array and false, respectively. T23 answers map its three public object labels to container labels; T05/T06 answers map public goal IDs to answers. Mapping keys come exclusively from public task text. T09–T11 additionally require `observed_objects` under their existing camera-bound declaration contract. Task declarations are validated before motion, logged separately and forwarded to deterministic evaluators; they never confer credit without the task's required evidence. Text markers in `world_observation` are ignored.

`survey_complete=true` pairs with command DONE and answer=null. An accepted declaration advances a requested survey without ending the whole task; T38 receives its delayed request at that boundary. An unmet prerequisite returns feedback and continues without a phase transition, terminal DONE or motion. Temporal Phase-1 plain DONE also retains its existing transition behavior. Ordinary DONE remains terminal. T52 still requires an explicit inside answer and active terminal DONE; they may occur in separate decisions of the same episode. Original-QA answer/confidence protocols remain separate from this physical-task schema. Generic original-QA sessions without that specialized protocol use the independent task fields too.

M4 additionally receives `simulation_clock` in its current action context. The elapsed simulation seconds share the evaluator's episode-start origin and are bound to the delivered snapshot, action step and capture timestamp. This is a sampled observation value, not wall time or a live clock while the model waits. It exposes no station-progress or completion flags.

Current authoring templates emit the structured response instructions. Historical generated definitions and source artifacts retain their original bytes; regeneration requires a new destination/version and review of later scene-specific revisions, not overwriting old outputs.

Use `--no-world-observation-log` with `python -m wia.runtime.commands.run_esi_explore_episode` to disable the observation string; the independent physical-task declaration fields remain. The explicit `--world-observation-log` flag enables the string. This choice and the response protocol are recorded in episode/session provenance. Programmatic callers can use `PromptAssembler(world_observation=False)`. Generic free-text transports do not use this modular prompt library.
